# European Dynamics vs 村田製作所 — 転職検討レポート

| 項目 | 内容 |
|------|------|
| 設立 | 1994年（アテネ） |
| 従業員数 | 約1,200名（7拠点） |
| 拠点 | アテネ、ベルリン、ブリュッセル、ロンドン、ウィーン |
| 事業内容 | 政府・国際機関向けITサービス・ソフトウェア開発 |
| クライアント | 30カ国以上、約100組織 |
| 売上 | 1億ユーロ超（二桁成長中） |
| CEO | Constantinos Velentzas（創業者、過半数株式保有） |

### 最近の動向（2025年）
- **CAPZA（仏）+ Abry Partners（米）からマイノリティ出資**を受け入れ（2025年夏完了予定）
- 創業以来初の外部資金調達
- **800名の技術者を新規採用予定**（主にギリシャ）
- フランス、北欧、DACH、米国への地理的拡大を計画
- AI分野への進出、M&A戦略も推進
- 欧米の大学とのパートナーシップ構築中

## 2. Glassdoorレビューから見るEDの実態

**総合評価: 3.3/5（279件）、68%が友人に推薦**

| カテゴリ | スコア (5点満点) |
|----------|-----------------|
| Work-Life Balance | 3.3 |
| Culture & Values | 3.2 |
| Career Opportunities | 3.1 |
| Compensation & Benefits | 3.2 |
| Senior Management | 2.8（推定） |

### Pros（良い点）
- フルリモート勤務が可能（ポジションによる）
- ギリシャ国内水準では給与は良い方
- 給与は時間通りに支払われる
- 政府系プロジェクトに関われる（EU機関など）
- キャリアスタートとしては悪くない

### Cons（悪い点）
- **最低9時間/日の勤務が求められる**（残業代なし）
- 「最低賃金以上の給与に残業代が含まれる」という契約にサインさせられる
- 仕事がなくてもオフィスに残ることを要求される
- **昇給・ボーナス・キャリアパスがない**
- マネジメントが粗い — 品質より納期を最優先
- 業務量の偏り（忙しい人と暇な人の格差）
- 建設的なフィードバックがない

### 給与水準（Junior Java Developer / アテネ）
- **月額 €916〜€1,467**（Glassdoor、25th〜75th percentile）
- 年額換算: **約€11,000〜€17,600**
- 日本円換算: **約180万〜290万円**（1€=165円想定）

## 5. 総合評価

### EDに行くメリット
1. **EU/国際機関でのキャリア形成** — 履歴書に「EU機関向けシステム開発」が載る
2. **日本からフルリモート**の可能性（確認必要）
3. **急成長フェーズ** — 投資直後で800名採用、新規市場進出中
4. **ヨーロッパのIT市場へのエントリーポイント** — 2〜3年後にEU内転職の足がかり
5. 多国籍・英語環境での実務経験

### EDに行くリスク
1. **年収が大幅ダウン** — 村田の半分以下になる可能性
2. **WLBは村田より悪い** — 9時間+労働、残業代なし
3. **キャリア成長の仕組みがない** — 昇給・昇進が不透明
4. **中小企業リスク** — 投資は入ったが上場大企業の安定性とは比較にならない
5. 日本からのリモートが本当に可能か未確定
6. ギリシャ水準の給与は日本の生活コストに合わない

### 結論

**純粋なWLB・待遇の観点では、村田製作所の方が圧倒的に上。**

EDへの転職が合理的なのは以下のケースのみ:
- **ヨーロッパ移住/EU圏でのキャリア構築が最優先目標**である
- 2〜3年のステップとして割り切れる（EDでEU経験→EU内の良い企業に転職）
- 日本からのフルリモートが確約され、ギリシャ水準ではなく交渉で適正な給与が得られる

**おすすめ**: 応募自体は進めつつ、オファー段階で「日本からのリモート可否」「給与水準（日本居住を考慮した額）」を必ず確認すること。条件が合わなければ断る選択肢を常に持っておく。
