# 1月の引っ越しに向けて断捨離とごみ処分を進める

- [ ] 10/5の定時後に15分だけ4区画を作り、衣類の引き出し1つを判定・記録する
- [ ] 朝の排出担当と高台2丁目の分別ステーション、古着・古紙の昼搬出経路を確認する
- [ ] 10月に衣類・台所小物・小型家電を選別し、10/23に袋数・未着手区画を確認する
- [ ] 11月に本・趣味機材・家具を整理し、11/18に粗大品目と寸法、11/25に残量を確認する
- [ ] 11/30に粗大ごみ第1便を申し込み、予約結果に合わせて搬出する
- [ ] 必要なら12/10に粗大ごみ第2便を相談し、12/23までに主要な処分を終える
- [ ] 旧居に残す消耗品を種類別にまとめ、在庫表と取りに来る箱を作る
- [ ] 1/6以降に荷造りを再開し、実際の入居日に合わせて準備完了目標を調整する

## 条件と計画上の期限

- 引越しは2027年1月予定。具体的な入居日・引越日は未確定。
- `due: 2026-12-23` は12/24〜1/5に作業できないため設定した、主要処分の計画上の締切。
- 1/22の準備完了目標は暫定。ユーザーが確定した引越日ではない。
- 平日は定時後または昼11:30〜12:15を利用。土日祝は原則使わない。
- 月45分・水60分の断捨離、火木の小説、金10分の記録。初回10/5は15分。
- 使えない日：10/7,9,12,28、11/6〜9,19〜24、12/24〜2027/1/5。
- 可燃は火金の当日朝8時まで、A/Bは当日7〜9時。朝の排出担当は確認待ち。
- 自己搬入は平日13〜16時。通常の昼休み・16時以降の定時後には入れない。
- 原付あり。レンタカーも利用可能だが、品目・量・利用時間が判明してから判断。
- 消耗品は旧居に残し、入居後も取りに来る。全面退去・全家具廃棄を前提にしない。
